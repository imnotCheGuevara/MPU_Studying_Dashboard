# Stage handoffs

Each stage conversation writes exactly one handoff named `stage-XX.md` using this structure:

```markdown
# Stage XX handoff

Status: PASS | PARTIAL | BLOCKED

## Delivered

## Changed files

## Acceptance evidence

| Acceptance item | Evidence/result |
| --- | --- |

## Commands run

## Manual checks

## Known limitations and risks

## Required follow-up
```

Do not include credentials, cookies, personal school data, raw private responses, or other secrets in a handoff.
